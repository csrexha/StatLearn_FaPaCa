# data

Place the raw data here. The data are not distributed with this repository.

- `raw_data.csv`: FaPaCa proteomics data, read by `read_raw_data()`
  ([`R/data_preparation.R`](../R/data_preparation.R)) in
  [`analyses/fapaca_study.R`](../analyses/fapaca_study.R).

The pipeline also writes the imputed data to `data/imputed_data.csv`.

The simulation study needs no input data: the data are generated by
`get_simulated_data()`.
